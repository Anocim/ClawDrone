# ClawDrone

Development and programming of an autonomous drone capable of detecting tennis balls from the air, navigating toward them, picking them up, and transporting and dropping them into a designated basket.

In order to improve the drone's functionality, a system could be developed to detect the shortest possible route for collecting the balls more quickly and, thus, completing the task more quickly.
